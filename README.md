# Linkly — frontend

Nowoczesny frontend skracarki linków z analityką, zbudowany w React + Vite.

## Start

```bash
pnpm install
pnpm dev
```

## Trasy
- `/` landing page
- `/login`, `/register`, `/reset-password`, `/verify` auth
- `/dashboard` przegląd + tworzenie linku
- `/dashboard/links` lista i usuwanie linków
- `/dashboard/links/summer` szczegóły + metadane wejść
- `/dashboard/account` konto
- `/r/summer` ekran przekierowania
- `/privacy`, `/terms` dokumenty

Projekt jest wyłącznie frontendem i korzysta z danych demonstracyjnych. Formularze oraz operacje na linkach symulują działanie UI lokalnie.
